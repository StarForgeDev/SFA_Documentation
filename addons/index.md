# Addon Documentation

This section summarizes the main SFA addon folders and what each page should eventually cover.

- [SFA Core](./core/) - factions, editor subcategories, shared classes, radios, and base references.

- [Medical, Boosts, and Grenades](./medical-boosts-grenades/) - stims, kolto, cryo, sonic, sticky, flashbang, and imploder tools.

## Content Packages

- [Equipment and Units](./equipment-units/) - Republic, Sith, neutral, Geonosian, Separatist, plague, races, and group configs.
- [Vehicles, Structures, and Terrain](./vehicles-structures-terrain/) - vehicles, ships, droids, structures, props, rocks, caves, trenches, and terrain assets.
