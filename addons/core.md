# SFA Core

Folder: `SFA_Core`

SFA Core is the shared foundation for the rest of the addon set. It defines faction classes, editor subcategories, shared base classes, and supporting equipment such as the holo comm radio.

## Factions

Important faction classes currently include:

- `SFA_Republic`
- `SFA_Republic_KOTOR`
- `SFA_Telos`
- `SFA_Empire`
- `SFA_Empire_KOTOR`
- `SFA_Revanites`
- `SFA_Mandalorian_Mercs`
- `SFA_Mandalorian_Neo`
- `SFA_Onderon`
- `SFA_Czerka`
- `SFA_HuttCartel`
- `SFA_Rakghoul_Rep`
- `SFA_Geonosian`
- `SFA_Mantellian_Separatist`
- `SFA_Umbaran`

## Editor Subcategories

Core editor subcategories are used by equipment, vehicles, structures, and unit packages. When adding content, prefer an existing matching subcategory instead of creating a new one casually.

Examples:

- `SFA_Infantry`
- `SFA_Infantry_Space`
- `SFA_Armor`
- `SFA_Helicopter`
- `SFA_Special`
- `SFA_Plane`
- `SFA_Turret`
- `SFA_Transport`
- `SFA_Car`
- `SFA_Artillery`
- `SFA_AntiAir`
- `SFA_Infected_troopers`
